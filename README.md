# Thani Nayagam Adigal — Digital Archive

A statically exported, multipage Next.js archive about Rev. Dr. Xavier S. Thani Nayagam Adigal. Designed for clear reading by older decision-makers: large type, high contrast, visible navigation, and sourced claims. No 3D models.

## Pages

- `/` — Home
- `/biography/` — Verified biography
- `/timeline/` — Chronology
- `/contributions/` — Work and selected writings
- `/archive/` — Licensed images and library records
- `/sources/` — Source list

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Static production build

```bash
npm run build
npm run preview
```

`npm run build` prerenders the site and writes the deployable static files to `out/`.
